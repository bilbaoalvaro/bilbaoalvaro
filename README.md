## Selected Projects

### Sales Analytics Dashboard

Interactive dashboard for analysing retail sales data using Python,
Pandas, Streamlit and Altair.

The project includes analysis of sales by store, state and product, as well
as seasonality, promotions, year-over-year growth and sales concentration.

### Machine Learning – Student Performance

Machine learning project focused on predicting student academic performance.

The project compares different approaches including KNN, logistic regression
and linear regression, together with techniques such as cross-validation,
PCA and K-Means.

### Amazon Reviews Data Platform

Data project combining Python and different database technologies to work
with Amazon review data.

The project includes SQL queries, MongoDB and Neo4j, together with data
analysis, visualization and graph-based queries.

### Time Series Forecasting

Time series analysis and forecasting using R.

The project covers exploratory analysis, decomposition, transformations,
differencing, ACF/PACF analysis, ARIMA/SARIMA models and residual diagnostics.

### Formula One Data Acquisition & Analysis

Data acquisition and analysis project based on Formula One data.

The project combines data collected from different sources and processes
it for further analysis and visualization.

### Madrid Route Planner

Python application for planning routes in Madrid using graph algorithms,
OpenStreetMap data and distance and travel-time comparisons.
